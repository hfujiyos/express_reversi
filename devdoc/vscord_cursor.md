# Cursor

## ショートカット

- ⌘ + I : AI チャットのウィンドウ表示
- ⌘ + K : カーソル範囲に対して、AI に「このコードを改善して」と自然言語指示
- ⌘ + L : 「AI によるコード編集モード」が有効になり、編集内容を自然言語で AI に伝えることで書き換えが可能
- ファイル全体に対して「このファイルを React Hooks に書き換えて」などと AI に自然言語指示
- 通常コマンドパレットに加え、「AI Command Palette」に「ユニットテストを書いて」などと自然言語指示
- AI が変更点をレビューしてくれる機能「このコミット、どう改善すべき？」などで AI レビュー
